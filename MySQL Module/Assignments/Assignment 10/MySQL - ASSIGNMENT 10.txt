Q2) Write a stored function Calculate_Bonus that takes salary as input
and returns bonus amount:
- If salary >= 80000 → bonus = 20%
- If salary between 50000 and 79999 → bonus = 10%
- Otherwise → bonus = 5%
Ans: mysql> delimiter #
mysql> create function calculate_bonus(salary decimal(10,2))
    -> returns decimal(10,2)
    -> deterministic
    -> begin
    -> if salary >=80000 then
    -> return salary *0.2;
    -> elseif salary >=50000 then
    -> return salary * 0.1;
    -> else
    -> return salary * 0.05;
    -> end if;
    -> end #
